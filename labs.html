AI Labs & Prototypes


Welcome to the experimentation core of Zinnia. Our labs are designed to explore ideas before the market is ready for them.


🧠 Diffusers for Incident Response

A preproduction framework combining Hugging Face and AWS tools to automate threat detection, phishing classification, and security ticket enrichment. Built from real-world SOC use cases.


🕸️ LLM Agents with Stateless Memory

Zero-persistence container agents that load custom memory shards from S3 using lightweight Redis proxies. Stateless by design. Ideal for secure enterprise workflows.


📊 Semantic Indexing for Compliance

DLI-style latent vector indexing to mine internal policy docs and audit logs. Optimized for legal/compliance departments operating under time pressure.


We publish whitepapers, open-source libraries, and run internal testbeds. Some labs are closed to the public but may be accessible via NDA partnership.
